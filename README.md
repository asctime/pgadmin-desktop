# pgAdmin Desktop

pgAdmin Desktop is an open source administration and development platform for PostgreSQL versions 9-19. The application runs on Linux, FreeBSD, Solaris, macOS and Windows, and manages PostgreSQL 8.2 and above on any platform, as well as commercial PostgreSQL derivatives such as EnterpriseDB Postgres Plus Advanced Server and Greenplum Database.

pgAdmin Desktop is designed for every kind of work, from simple SQL queries to complex databases. The graphical interface supports PostgreSQL features and makes administration straightforward. It includes a syntax-highlighting SQL editor, a server-side code editor, an SQL/batch/shell job scheduling agent, support for the Slony-I replication engine, and more. Server connections use TCP/IP or Unix domain sockets (on Unix platforms), and may be SSL encrypted. No additional drivers are required to communicate with the database server.
